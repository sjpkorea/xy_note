xy_note (xython을 활용한 자동화 프로그램) 다운로드

📌 프로그램 소개

이것은 xython 패키지를 쉽게 사용할 수 있도록 GUI 형식의 프로그램으로 만든 것입니다. 특정 폴더 안에 압축을 풀면 xy_note_v15_pu라는 형태로 폴더가 만들어집니다.

주의사항: 다운로드가 완료된 후, xy_note_v15_pu.exe를 클릭하면 자동 압축 해제 프로그램이 실행됩니다.

💡 간단한 사용 설명

  • 폴더 이동: xy_note_v15_pu 전체를 원하는 곳으로 이동하셔도 실행하는 데 문제는 없습니다.
  • 프로그램 실행: 메인 폴더 아래의 xy_note_cs11.exe을 실행하시면 프로그램이 시작됩니다. (사용법은 실행된 프로그램 안의 매뉴얼을 참조하세요)
  • Python 환경: 사용에 필요한 기본적인 Python 환경은 python 폴더 안에 모두 들어있으며, 각 필요한 부분들은 이것을 불러서 실행합니다.
  • 메인 프로그램: C# (CSharp)을 이용해 만들었습니다.
  • 자료 실행: folder_main 아래의 폴더와 자료들이 나타나며, 필요한 파일을 선택한 후 "실행" 버튼을 누르면 실행됩니다.

📂 folder_main 폴더 구조

  • 업무 각 사용자가 알아서 이곳에 코드를 만들어서 넣어서 사용하는 곳으로 비어있습니다.
  • 2_일반 공식 사이트에서 사용하기 좋은 것들을 GUI가 아닌 각자 사용법을 익히기 위한 기본 자료입니다.
  • 3_공식자료들 차후에 공식 자료의 추가 기능들을 배포하기 위한 것입니다.
  • 4_개별_gui 기능들을 좀 더 사용하기 편하게 하기 위하여 개별 GUI 형태로 사용 가능하도록 만든 것들입니다.
  • 5_xy_builder 프로그램을 블럭처럼 만들어서 사용 가능하도록 만드는 중입니다.
  • 6_test용_자료만들기 엑셀용 공부나 테스트를 위한 자료를 쉽고 빠르게 만들 수 있도록 한 것입니다.
